# Frontend

React + Vite customer storefront for Vadhiyar Agrotech with multi-language, branded UI, and cart/checkout flows.

## Setup
1. Run `npm install` inside `frontend`.
2. Create a `.env` file from `.env.example` if you need to override the backend base URL.
3. Start the dev server with `npm run dev` (default port 5173 by Vite).

## Features
- Public home page, product listing, and detail pages.
- Language switcher (English/Hindi/Gujarati) for labels, buttons, and messages.
- Cart, checkout, and order history (requires customer login).
- Authentication integrates with the backend API via JWT.
- Agriculture-inspired styling with the Vadhiyar Agrotech logo.
